## 실제 앱 조작 증거

API 35 `Pixel_9_ASCII`에서 ADB로 실제 실행했다. 새 테스트를 작성한 것만으로
수동 동작 확인을 대신하지 않았다.

1. 빈 제목으로 추가하여 한국어 오류 표시를 확인했다.
2. `  Persist Task  `를 입력하고 키보드 Enter로 추가했다.
   화면에는 앞뒤 공백 없는 `Persist Task`가 표시됐다.
3. 프로세스를 강제 종료하고 다시 실행해 해당 제목이 남는 것을 확인했다.
4. 체크박스를 눌러 완료 → 완료 취소 → 완료로 변경하고 checked 상태를 확인했다.
5. `Delete Me`를 추가한 뒤 그 항목의 삭제 버튼을 눌렀다.
6. 다시 `am force-stop com.example.aiprgate` 및
   `am start -W -n com.example.aiprgate/.MainActivity`를 실행했다.
   `Persist Task`는 완료로 남고 `Delete Me`는 없는 것을 확인했다.
7. 긴 시험용 제목, 두 테마, 가로 화면과 스크롤 끝을 캡처했다.

초기 `Room Study` 좌표 조작은 Gboard 물리 키보드 도구막대와 충돌했다.
이를 완료 상태 검증 성공으로 세지 않는다. Gboard 마이크 안내는 앱 권한 요청이 아니다.
이후 위 `Persist Task` 시나리오를 IME가 숨겨진 재실행 화면에서 다시 확인했다.
`docked-keyboard-dark.png`라는 파일명과 달리 실제로는 아래로 옮긴 플로팅 키보드다.
일반 하단 고정 키보드의 IME inset 검증 완료로 확대 해석하지 않는다.

### 일반 하단 고정 IME 추가 검증

초기 독립 AI 검토에서 고정 IME 증거가 부족하다는 지적을 받았다.
앱 코드는 수정하지 않고 Gboard 자체 설정을 확인했다. 시스템의
Use on-screen keyboard는 켜져 있었지만, Gboard의 Physical keyboard 내
Show on-screen keyboard는 꺼져 있었고 Show toolbar는 켜져 있었다.
시험 동안 Gboard의 Show on-screen keyboard를 켜 하단 고정 Gboard를 표시했다.
도구막대 옵션도 조작했지만 복원 전 관측에서는 켜져 있었으므로
도구막대를 껐기 때문에 해결됐다고 단정하지 않는다.

- 세로: 입력란·추가 버튼이 키보드 위에 표시된다.
  `Docked Add`를 추가 버튼으로, `Docked Done`을 화면 키보드의 완료 키로 등록했다.
- 가로: 입력란으로 포커스하면 자동 스크롤되어 입력이 가능하다.
  위로 스크롤해 추가 버튼에 접근하여 `Landscape Add`를 등록했다.
  `Landscape Done`은 화면 키보드의 완료 키로 등록했다.
  키보드를 닫고 목록 끝에서 두 항목을 확인했다.
- 밝은/어두운 테마에서 실제 고정 키보드를 캡처했다.
- 시험용 스타일러스 설정 변경만으로는 키보드 모드가 바뀌지 않았다.
  이는 해결 방법으로 기록하지 않는다.

추가 증거:
`ime-docked-portrait-light.png`, `ime-docked-portrait-dark.png`,
`ime-docked-landscape-dark.png`,
`ime-docked-landscape-scrolled-light.png`,
`ime-docked-landscape-scrolled-dark.png`,
`ime-landscape-submissions.png`.
가로에서 입력란이 보이는 장면과 추가 버튼까지 스크롤한 장면을 구분한다.
후자의 위쪽에 입력란 일부가 잘린 것은 스크롤 위치이며,
입력이 불가능하거나 추가 버튼이 키보드에 고정적으로 가려진 상태가 아니다.

검증 후 이번에 추가한 시험용 항목 6개를 화면에서 삭제했고 재실행 후 빈 목록을 확인했다.
회전 값 0, 자동 회전 0, 스타일러스 필기 값 없음,
Gboard Show on-screen keyboard 꺼짐/Show toolbar 켜짐 상태로 복원했다.
시스템의 Use on-screen keyboard는 원래 값인 켜짐을 유지했다.

새 독립 AI 검토자가 기존·추가 캡처 16개와 소스·저장된 테스트 결과를 읽고 PASS를 반환했다.
제품·증거 차단 항목은 없었다. 독립 검토자의 직접 기기 재조작이나 별도 테스트 재실행은
아니며 사람이 승인한 것으로 표시하지 않는다. 상세 범위·한계는
`results/app-20261025/visual-qa.md`에 기록했다.
