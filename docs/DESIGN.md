# AiPrGate Android 화면 설계

## PR 관리 앱

기존 Material 3 테마·시스템 글꼴·동적 색상·밝기 모드를 이어 쓴다.
리뷰어가 최신 변경과 근거를 먼저 읽고 승인하는 작업 도구다.
새 웹 디자인·장식 이미지·색상 띠·무의미한 애니메이션을 도입하지 않는다.

### 토큰과 탐색

- 색상·타이포·모양: MaterialTheme.colorScheme/typography/shapes.
- 관리 앱의 본문·제목에는 한국어 locale과 Paragraph 줄바꿈을 적용한다.
  본문은 17sp, 보조 본문은 15sp다. 날짜는 한국어 지역 형식으로 표시하고
  샘플의 기존 타이포는 유지한다.
- 간격: 4/8/12/16/20/24/32dp. 바깥 20dp, 그룹 16dp, 관련 항목 8dp.
- 관리 화면 콘텐츠 최대 840dp, 연결 폼 최대 640dp. 넓은 화면에서는 가운데 배치.
- 상태는 텍스트를 항상 병기하고 오류에는 errorContainer/onErrorContainer를 사용한다.
- 헤더·필터·탭은 별도 고정 영역, 본문은 화면별 단일 LazyColumn이 스크롤한다.
- diff만 별도 가로 스크롤을 허용한다. 파일명·본문은 줄바꿈한다.
- 시스템 바와 키보드 여백을 소비한다. 글자 크기 확대 시 버튼은 줄바꿈하며 접근 가능해야 한다.

### 재사용 컴포넌트와 상태

- 관리 헤더: 화면 제목·저장소·뒤로 가기, 연결 설정과 새로고침은 텍스트 버튼.
- 상태 배지: 중립 tonal surface에 짧은 한국어 상태. 색상만으로 전달하지 않는다.
- PR 카드: 번호·상태, 제목, 작성자·갱신일. 클릭 시 상세 이동.
- 안내 카드: 제목·원인·다음 동작. 로딩·빈 목록·인증 필요·조회 오류를 구분한다.
- 상세 탭: 요약/변경/검사/리뷰. 선택 상태는 Material 기본 indicator로 표시한다.
- 검사 카드: 이름·상태·기준 SHA·실패 요약·GitHub 근거 열기.
- 입력: 항상 보이는 라벨, 토큰은 비밀번호 표시, 상태 복원과 스크린샷에서 토큰 제외.
- 비활성 입력·버튼도 onSurfaceVariant로 읽을 수 있게 표시하며 활성색과 구분한다.
  저장소는 URI, Client ID는 ASCII, 토큰은 Password 키보드 유형을 지정한다.
- 리뷰 폼: 의견 보존, 제출 전 event와 불변 PR 대상을 확인하는 AlertDialog.
- 병합 폼: 조건·차단 사유와 방법을 표시, 파괴적 동작은 기본 키보드 동작으로 실행하지 않는다.
- 확인 대상은 저장소·PR 번호·head/base SHA·대상 브랜치다. 대상 변경 시 확인창을 닫는다.
- 네트워크 쓰기 중 중복 실행·화면 전환에 의한 대상 변경을 막고 결과를 재조회한다.
- 오프라인·권한 부족·조회 오류는 성공으로 보이지 않는다. 실패 시 재시도 동작을 제공한다.

### 접근성과 검증

Material 기본 48dp 터치 영역·시스템 Back·IME 동작을 유지한다.
본문·SHA·오류·diff는 복사할 수 있게 한다.
장식 모션은 없으며 Material 기본 전환만 사용한다.
Android 기기에서 연결/빈 목록/목록/상세 네 탭/리뷰 확인/병합 확인/오류와
기존 샘플을 밝고 어두운 모드로 캡처한다.
인증 정보·실제 쓰기가 없어 확인하지 못한 상태는 별도 기록한다.

## 보존하는 팀 학습 할 일 샘플

기존 AiPrGate Material 3 테마, 시스템 글꼴, 동적 색상과 시스템 밝기 모드를 유지한다.
웹 UI·새 디자인 시스템·외부 이미지·추가 스타일 의존성은 도입하지 않는다.

## 구성과 간격

- 한 화면: 제목, 설명, 입력 폼, 목록 순서.
- MaterialTheme의 colorScheme, typography, shapes를 사용한다.
- 바깥 여백 20dp, 관련 요소 간격 8dp, 그룹 간격 16dp.
- 콘텐츠 최대 너비 640dp. 넓은 화면에서는 가운데에 배치한다.
- 단일 LazyColumn이 입력 폼과 목록 전체의 세로 스크롤을 소유한다.
- Scaffold의 시스템 바 여백을 소비하고 IME 여백을 추가한다.

## 컴포넌트와 상태

- 제목: headlineSmall, '팀 학습 할 일'.
- 입력: OutlinedTextField, 항상 보이는 '할 일 제목' 라벨, 단일 행.
- 주 동작: 채워진 '추가' 버튼. 빈 입력도 제출 가능하며 필드 아래 오류를 표시한다.
- 항목: 체크박스, 줄바꿈 가능한 제목, error 색상의 '삭제' TextButton.
- 완료: 체크 표시와 취소선을 함께 사용하며 색상만으로 전달하지 않는다.
- 로딩: 짧은 한국어 안내. 빈 목록은 추가 방법을 안내한다.
- 저장 중: 중복 제출을 막기 위해 편집·추가·변경·삭제를 비활성화한다.
- 오류: 입력 오류와 읽기/쓰기 실패를 구분한다. 저장 실패 시 입력을 유지한다.
- 키보드 완료 키는 추가만 실행하며 삭제는 실행하지 않는다.
- 터치 영역은 Material 기본 최소 크기를 유지한다. 체크박스와 삭제의 접근성 이름에 항목 제목을 포함한다.

## 검증

실제 Android 화면에서 빈 목록, 입력 오류, 미완료/완료, 긴 제목, 키보드,
밝은/어두운 모드와 가로 화면을 확인한다. 미실행 상태는 통과로 기록하지 않는다.
