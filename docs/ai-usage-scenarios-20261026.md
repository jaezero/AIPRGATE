## 사용자 요청과 결정

- 서류의 '데모' 표기를 없애고 실제 결과물로 발표하기 위해 현재 앱의 부족한 점 확인을 요청했다.
- 팀원 초대 없이 진행 가능한지 물었고, **1인 운영 모드**로 진행하기로 했다.
- 원격 저장소 push와 보호 설정 적용을 허락했다("진행해").
- 개인 토큰을 직접 발급해 앱에 입력했다. 토큰은 대화로 전달하지 않았다.
  첫 시도에서 토큰을 잘못된 칸(Client ID)에 넣어 화면 캡처에 일부가 보였고, 캡처는 즉시 삭제했으며 재발급을 권고했다.
- AI 리뷰봇을 차별점으로 요청했고, Max 구독 토큰을 `CLAUDE_CODE_OAUTH_TOKEN` 시크릿으로 직접 등록했다.
- AI 리뷰 댓글에 커밋 코드 요약을 넣도록 요청했다.
- 실제 개발 사례로 간단한 로그인 기능을 요청했다.
- PR 상태 용어('열림/닫힘')가 이해하기 어렵다고 지적했다.
- 모든 자기 검토와 병합 버튼은 **사용자가 직접** 앱에서 눌렀다. AI는 확인창을 열거나 화면을 캡처했지만 제출하지 않았다.
